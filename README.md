# NovaTech Revenue Intelligence & Executive Analytics

**Author:** Tanzila Ahmmed  
**Project:** Udacity Generative AI / Analytics Project  

## 📌 Project Overview
This project presents an end-to-end data integration, interactive dashboard analysis, and AI-powered querying setup for **NovaTech**. By combining CRM sales pipeline data, marketing campaign performance, and customer support ticket resolution logs, this project delivers actionable business intelligence for executive decision-making.

---

## 📂 Deliverables Included in Submission
The repository contains `Tanzila_Ahmmed_NovaTech_Submission.zip`, which includes all mandatory project files:

1. **NovaTech_Data_Transformation_Report** — Data join configurations, schema corrections, and calculated fields.
2. **NovaTech_Verification_Log** — Pre-indexing data verification log covering CRM, Marketing, and Support datasets.
3. **NovaTech_Executive_Report** — Strategic executive report prepared for VP Sarah Chen.
4. **NovaTech_Annotated_Dashboard_Screenshots** — Visual dashboard sheets with quantified business annotations.
5. **NovaTech_Q_Topic_Comparison_Report** — Amazon QuickSight Q topic natural language query exploration and comparison logs.
